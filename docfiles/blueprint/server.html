Server Queue Subsystem​

Game Instance subsystem, active on the server.

Function / eventDescription
Is ActiveWhether the queue runs on this server
Reload SettingsRereads settings and recreates providers, like ServerQueue.Reload
Get Queue LengthPlaces in the queue; a party counts once
Get Num Waiting PlayersWaiting players, party members included
Get Num Players In GamePlayers in the game
Get Num Free SlotsFree slots
Remove PlayerRemoves a waiting player or cancels their unused reservation. Removing a party leader takes the party out of the queue
Set Player PrioritySets a player's priority until the next reload and reorders the queue
On Queue Status ChangedThe queue or the slots changed, for example to publish the numbers to your own server list

Server Queue Beacon Host Subsystem​

World subsystem on the server. With Auto Start Beacon Host on (the default) the beacon starts by itself when a server world begins play, so you only need it to control the beacon yourself.

FunctionDescription
Start Beacon HostStarts listening on the beacon port
Stop Beacon HostStops the beacon
Is HostingWhether the beacon is listening
